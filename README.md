# AIニケちゃんサーバー 1周年 お祝いページ（制作中）

公開URL: https://nike-anniversary-lp.pages.dev

AIニケちゃんさんのDiscordサーバーが **2025年8月23日** に開設されて1年になるのを記念した、
非公式のお祝いページです。ツキ（[@tukikage2](https://x.com/tukikage2)）とAIネクタリカが作っています。

## このページの構成

年表を **2本の線** で並べています（現在 **97件**）。

| 列 | 中身 | 件数 |
|---|---|---|
| 🌍 世界の生成AI | 同じ1年に、世界の生成AIに起きたこと | 66 |
| 🏠 ニケちゃんサーバー | 同じ時期に、この界隈で起きたこと | 31 |

「あの技術が出たとき、ここでは何が起きていたか」を並べて見えるようにするのが狙いです。

**左の列は誰でも調べられますが、右の列はこの1年ここに居た人にしか書けません。**
右の列にはまだ「サーバーの中で起きたこと」が入っていません。これから集めます。

### ジャンル

`category` で絞り込めます。

| ジャンル | 中身 |
|---|---|
| LLM / 画像生成 / 動画生成 | 世界側のモデル・ツールのリリース（一部は手元側にも付く） |
| 制作 | ニケちゃんさんが公開したもの（GitHubの公開リポジトリから） |
| Xポスト | `#AIニケちゃん` タグで起きたこと |
| サーバー | 起点となる出来事 |

### 「開設前のできごと」について

**サーバーが開く前**の項目が12件あります。既定では閉じていて、ボタンを押すと開きます。

- 世界側 = 開設した日に、すでに世界にあった道具（LLM・画像・動画）
- 手元側 = **`#AIニケちゃん` タグが用意された日（2025年8月3日＝開設の20日前）**

**場所ができる前に、集まる目印のほうが先にありました。** それが見えるように残しています。

## 年表データについて

年表の中身は [`public/data/timeline.json`](public/data/timeline.json) にあります。
HTMLには年表を1件も埋め込んでいないので、このJSONを見れば掲載内容がすべて分かります。

### 日付の扱い（このページで一番気をつけたところ）

年表は日付が主役なので、**もっともらしい日付を根拠なしに載せない**ことを最優先にしています。

- **1件につき出典URLを必須**にしています（97件すべてに入っています）。
  世界側は開発元の公式ブログ・公式リリース・公式ドキュメントのみで、まとめ記事やニュースサイトは一次情報の代用にしていません
- **裏取りできなかった4件は、日付を空のまま `status: "draft"` で残しています。**
  ページ上では日付を出さず `20XX.XX（仮）` と表示されます。
  埋まって間違っているより、空欄のほうが正確だと考えています
- **日まで確定できないものは月で止めています**（`date_precision: "month"`）
- 日付が確定した行は、**ページ上の日付が出典リンクになっています**。クリックすると出典へ飛びます
- 件数を数え切れていないものは、**件数を書きません**（例＝タグの投稿数）。
  網羅できていないのに数字を出すと、網羅した顔になってしまうためです

### 出典の内訳（`verified_by`）

| 値 | 件数 | 意味 |
|---|---|---|
| `codex` | 65 | 各社の公式発表を収集 |
| `nectalica-github-api` | 22 | GitHubの公開リポジトリ（作成日・リリース日・READMEの実物） |
| `nectalica-xai-search` | 6 | `#AIニケちゃん` タグの調査 |
| `tsuki` / `tsuki+…` | 2 | 本人のポストを出典として受け取ったもの |
| `nectalica` | 2 | 案内カードなど |

### Xポストの扱い（ここは方針として書いておきます）

`#AIニケちゃん` タグの項目には、**個人のアカウント名も個別ポストのURLも載せていません。**
出典はタグの検索URLにしています。

タグ付きの公開ポストであっても、**本人の同意なく、個人の投稿を固定ページに並べることは避ける**という判断です。
唯一の例外は、**ニケちゃんさん本人がタグを告知したポスト**で、これは告知そのものなので出典として載せています。

### 名前の表記

モデル名は **通称** で書いています。正式名は `alias` に併記しました。

```json
"title": "Nano Banana、会話型の画像編集モデルとして登場",
"alias": ["Gemini 2.5 Flash Image", "Nano Banana", "nanobanana"]
```

正式名だけで書くと、当時の盛り上がりを思い出せる人がいなくなるためです。

### 対象期間

**2025年8月 〜 2026年9月**（サーバー開設からニケフェス開催月まで）。

## 誤りを見つけたら

日付や内容の誤りに気づいた方は、Issue か Pull Request で教えていただけると助かります。

`timeline.json` に1件足すだけでも構いません。フォーマットは既存の行をそのまま真似てください。
